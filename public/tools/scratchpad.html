About

A single note for quick ideas. Click below the title and start typing. Type / at the start of a line for the block menu. A line shows its Markdown while you edit it and renders when you click away. Everything is saved as you type, only in this browser on this device, and nothing is sent anywhere.

Line starts

# ## ###Heading 1, 2, 3
- or *Bulleted list
1.Numbered list
[]To-do with checkbox
>Toggle (hides the lines indented beneath it)
"Quote
```Code block (Enter adds lines, Ctrl/Cmd+Enter leaves it)
---Divider
/Block menu, including Image

Inline

**bold**Bold (Ctrl/Cmd+B)
*italic*Italic (Ctrl/Cmd+I)
`code`Inline code (Ctrl/Cmd+E)
~~struck~~Strikethrough (Ctrl/Cmd+Shift+X)
==text==Highlight
[text](url)Link. Bare https links also become clickable.

Keys

EnterNew block. Enter on an empty list item ends the list.
Tab / Shift+TabIndent or outdent a block and what sits beneath it
Alt+Up / DownMove a block up or down
Backspace at startTurn a block back into plain text, outdent, then merge with the line above
Ctrl/Cmd+EnterTick a to-do, or open and close a toggle
PasteMulti-line Markdown becomes blocks. Images become image blocks.

Images are shrunk to 1600 px on their longest side before they are stored. Copy Markdown puts the whole note on your clipboard. Clear asks once, then starts over.
