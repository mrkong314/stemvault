Assignment and output


x ← 5           # assign 5 to x
x ← x + 1
print x
print(i, i^2)    # prints (3, 9)
input a, b       # values come from the box above the output

          
Type <- to get ←. Reserved words are shown in bold, as in the exam.


          
Decisions


if a ≤ b then
    print a
else if a = b then
    print "equal"
else
    print b
end if

          
Comparisons: = ≠ < > ≤ ≥. Combine with and, or, not.


          
Repetition


for i from 1 to n        # 1 to n inclusive
    print i²
end for

while x² < 1000
    x ← x + 1
end while

          
An optional step is accepted: for x from 0 to 1 step 0.1.


          
Functions


define f(x)
    return x³ − 2x − 5

define factorial(n):
    product ← 1
    for i from 1 to n
        product ← product × i
    end for
    return product

          
Indent the body under the define line. A colon after the header is optional.


          
Arithmetic

          
+ − × or *, ÷ or /, ^ for powers (² and ³ also work), mod for remainders. Writing 2x, 3(a + b) or 2πr multiplies, as in maths.


          
Built-in functions

          

            
random()random real number in [0, 1)

            
random(a, b)random real number in [a, b)

            
randominteger(a, b)random integer from a to b inclusive

            
sqrt, abs, floor, ceilroot, absolute value, rounding down and up

            
round(x, d)round to d decimal places (d optional)

            
sin, cos, tan, asin, acos, atanradians

            
exp, ln, log(x, b), log10ln and log are both base e unless a base is given

            
pi, econstants (π also works)

            
min, max, sum, mean, lengthwork on lists: L ← [2, 5, 1], L[1] is the first item

            
append(L, x), sort(L), count(L, x)add to, sort, or count within a list

            
factorial(n), ncr(n, r)n! and the binomial coefficient
