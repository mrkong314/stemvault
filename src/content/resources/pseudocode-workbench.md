description: "Write and run pseudocode using the VCE Mathematical Methods conventions. An editor with syntax highlighting and insert buttons for if, for, while, define and the arrow, inequality and operator symbols feeds a built-in interpreter that runs the whole program or steps it one line at a time, highlighting the current line and showing every variable as it changes. A trace table records variable values after each line, matching the exam-style trace tables students fill in by hand, and a reference tab summarises the conventions and built-in functions. Sixteen loadable examples cover the study design uses of algorithms: perfect squares, factorial, the trapezium rule and rectangle sums, bisection, numerical derivatives from a limit, integer optimisation, dice and coin simulations, sampling distributions, Monte Carlo estimation of pi and binomial probabilities by counting. Variables and functions the program has defined are coloured once recognised, and an optional suggestion list completes names, keywords and built-in functions with the arrow keys and Tab. Plain-English error messages point to the offending line, and the code is kept in the browser between visits."
