description: "Write and run programs in the syntax of the CAS calculator used in VCE Mathematical Methods: Define with Prgm or Func, the store arrow and :=, Disp, Request, If/Then/ElseIf/EndIf, For/EndFor, While/EndWhile, Loop/Exit, Local and the usual built-in functions such as randInt, nCr, seq and the list functions. An editor with syntax highlighting and insert buttons feeds a built-in interpreter that runs the whole program or steps it one line at a time, highlighting the current line and showing every variable as it changes. A trace table records variable values after each line, matching the exam-style trace tables students fill in by hand, and a reference tab summarises the syntax and built-ins. Seventeen loadable examples cover the study design uses of algorithms: perfect squares, factorial, the trapezium rule and rectangle sums, bisection, numerical derivatives from a limit, integer optimisation, dice and coin simulations, sampling distributions, Monte Carlo estimation of pi, binomial probabilities by counting and lists built with seq. Variables and functions the program has defined are coloured once recognised, and an optional suggestion list completes names, keywords and built-in functions with the arrow keys and Tab. Plain-English error messages point to the offending line, and the code is kept in the browser between visits."
